# Release Readiness Matrix

Prepared by an autonomous pre-release audit pass (2026-08-16), auditing the M00-M28 build-out
plus post-M28 follow-up work against the repository/PR/CI state as actual source of truth (not
assumed from prior session summaries). Supersedes the per-item audit embedded in
`docs/RELEASE_CHECKLIST.md` — read that file for the original Release Candidate checklist and
`docs/DECISIONS.md` for the reasoning behind every entry below.

Legend: `VERIFIED` (tested against real data/a real invocation, not just unit-tested in
isolation) · `VERIFIED_WITH_LIMITATION` (real and tested, but with an acknowledged scope gap) ·
`LIVE_VERIFICATION_REQUIRED` (built and tested against fixtures/synthetic data; needs a real,
reachable network + API key to fully verify) · `CODEX_REVIEW_PENDING` · `HUMAN_GATE` (blocked on
a decision only a human can make) · `BLOCKED` (blocked on something else, e.g. infrastructure not
yet decided).
